# Contributing to Flama G2P

Flama G2P is distributed under a source-available, dual-licensing model (free for non-commercial use under the PolyForm Noncommercial License 1.0.0, and requiring a separate commercial license from Flama for any commercial use).

To preserve the ability of the project owner to relicense, modify, redistribute, and commercially license the G2P codebase, external code contributions cannot be accepted without a contributor agreement.

Until an appropriate contributor agreement process is established, external code contributions to the Flama G2P implementation should not be merged.
