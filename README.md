# Flama G2P

Flama G2P is a Grapheme-to-Phoneme (G2P) conversion implementation for Flama Audio.

## Features
- Converts text (graphemes) to phonetic representation (phonemes) to prepare the input for the Kokoro Text-to-Speech (TTS) engine.
- Currently supports English (US/UK) and Chinese (Mandarin).
